# Credit-Card-Financial-Report
A Credit Card Financial Analytics project using SQL and Power BI, featuring interactive dashboards to analyze revenue, transactions, customer behavior, card categories, and key financial KPIs.
Project Steps
1. Project Overview
- Understanding the business requirements and objectives.
- Identifying important KPIs such as revenue, transaction amount, transaction count, interest earned, and customer satisfaction.
- Planning the Power BI dashboard and required visualizations.
2. Data Extraction
- Data was stored in a MySQL database.
- Connected MySQL with Power BI.
- Extracted data from the credit_card and Customer_detail tables.
- Loaded the required data into Power BI for further analysis.
3. Data Processing & DAX Queries
- Cleaned and transformed the data in Power BI.
- Created calculated columns and measures using DAX.
- Created customer age groups and other required categories.
- Applied sorting, filtering, and data modeling to prepare the data for analysis.
4. Dashboard & Insights
- Designed an interactive Credit Card Financial Dashboard in Power BI.
- Added KPI cards, charts, filters, and slicers.
- Analyzed revenue, transactions, customer demographics, card categories, and other financial metrics.
- Generated meaningful business insights from the dashboard to understand customer and financial performance.
